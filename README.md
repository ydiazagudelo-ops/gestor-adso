# Gestor ADSO

## 1. Nombre del Proyecto
**Gestor ADSO** - Proyecto Integrador del programa Análisis y Desarrollo de Software.

## 2. Objetivo del Proyecto Integrador
Desarrollar una aplicación web integradora en Laravel para la gestión eficiente de procesos, evidencias y actividades en el programa de formación ADSO del SENA.

## 3. Versiones Verificadas del Entorno
- **PHP:** 8.2.12
- **Laravel:** 12.x
- **Composer:** 2.x
- **Node.js:** 20.x (LTS)
- **npm:** 10.x
- **MariaDB / MySQL:** 10.4 / 8.0 (Ejecutándose en el puerto `3307`)

## 4. Pasos para Instalar Dependencias
Desde la raíz del proyecto, ejecutar los siguientes comandos en la terminal:

```bash
# Instalar dependencias del backend (PHP)
composer install

# Instalar dependencias del frontend (JavaScript y Vite)
npm install
